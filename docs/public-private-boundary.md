# Public/private boundary

## Public repository may contain

- sanitized software and tests;
- schemas and adapter contracts;
- approved English and Spanish release copy;
- public architecture and installation documentation;
- versioned attribution and license records.

## Private lab only

- supplied PDF, DOCX and workshop videos;
- source hashes and provenance details;
- clinical claims register and review notes;
- rights correspondence and approval evidence;
- private pilot material or personal RCP entries.

## Export rule

Nothing is copied from the private lab to the public repository by default. A release export must prove:

1. canonical source and version;
2. rights cleared for the exact artifact;
3. claims and safety review complete;
4. English/Spanish semantic parity;
5. four-runtime installation and safety tests;
6. no raw source, personal data or hidden transcript retention;
7. Fer-approved attribution and release wording.
